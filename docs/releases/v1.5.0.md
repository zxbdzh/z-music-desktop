# z-music-desktop v1.5.0

Desktop 1.5 is the first stable desktop release from the independent
`z-music-desktop` repository. It supports Windows 10 and Windows 11 x64 and
ships an unsigned Setup package and a portable package.

## Highlights

- Completes the Desktop RC navigation, search, library, settings, playback,
  feedback, theme, accessibility, and reduced-motion acceptance work.
- Preserves the historical `cn.toside.music.desktop` application ID,
  `ikun-music-desktop` user-data directory, `lxmusic://` URL scheme, and
  `lx-music-protocol` registration so 1.4.5 users retain settings, lists, and
  OAuth callbacks.
- Adds deterministic Windows x64 Setup and portable artifacts, SHA-256 sums,
  a version manifest, and install/uninstall evidence bound to one commit.
- Includes `LICENSE`, `NOTICE`, upstream attribution, and compatibility notes
  in every desktop package.

## Upgrade

Exit version 1.4.5 before running the 1.5.0 installer. The installer runs for
the current user without requiring administrator privileges. Existing data in
`%APPDATA%\ikun-music-desktop\LxDatas` remains in place and is read directly;
the upgrade does not copy, rename, or delete it.

The portable package stores data in a `portable\userData` directory beside the
portable executable when that `portable` directory exists. It does not migrate
or modify installed-user data.

## Compatibility identifiers

The following historical identifiers intentionally remain unchanged:

- Application ID: `cn.toside.music.desktop`
- Existing user-data directory: `ikun-music-desktop`
- URL scheme: `lxmusic://`
- Protocol display name: `lx-music-protocol`
- OAuth callback: `lxmusic://oauth/callback`

Changing these identifiers would break upgrades, deep links, or third-party
OAuth registrations.

## Third-party services

Music sources, WebDAV servers, Last.fm, user-configured NetEase services,
AurioClub, and Voxrail are third-party or user-configured network services.
Their availability, authentication, content, and regional behavior are not
controlled by this project. Credentials remain in the existing user profile
and are not included in release evidence.

## Known limitations

- Windows packages are unsigned. Windows SmartScreen may show an unknown
  publisher warning. SHA-256 values in `SHA256SUMS.txt` are the integrity
  source for this candidate.
- Windows 7, Windows x86/arm64, and Linux arm64/armv7l are not supported by
  Desktop 1.5.
- macOS x64/arm64 and Linux x64 packages are best-effort build signals and are
  not part of the blocking interaction matrix.
- Network-backed features can be unavailable when their third-party service is
  offline, incompatible, or rejects the user's credentials.

## Rollback to 1.4.5

1. Exit z-music-desktop and make a copy of
   `%APPDATA%\ikun-music-desktop\LxDatas`.
2. Uninstall z-music-desktop 1.5.0. The uninstaller is configured to preserve
   application data.
3. Install the archived 1.4.5 x64 package from the legacy release.
4. Start 1.4.5 and verify settings and lists from the same historical data
   directory.

Rollback never requires deleting user data. Do not remove or rename the
historical directory. Data created by newer features should remain backed up
if an older version does not understand it.
